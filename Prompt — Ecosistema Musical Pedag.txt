# Prompt — Ecosistema Musical Pedagógico Web

Quiero desarrollar un ecosistema completo de aplicaciones web musicales orientadas al trabajo pedagógico de un profesor de música escolar.

El objetivo principal es dejar de depender de:

* notebook personal
* DAWs pesados
* software complejo
* archivos PPT
* múltiples aplicaciones separadas

Todo debe funcionar:

* desde navegador
* en cualquier computador
* en celular
* en tablet
* idealmente offline mediante PWA

---

# Filosofía general

NO quiero replicar software profesional complejo.

Quiero herramientas:

* rápidas
* musicales
* minimalistas
* pedagógicas
* interconectadas

Cada app debe hacer pocas cosas, pero muy bien.

---

# Apps principales

## Cuaderno MIDI

Captura rápida de melodías y creación de MIDIs estructurados.

## Metalófono App

Práctica visual y pedagógica basada en MIDI.

## Flauta App

Digitaciones y ejercicios interactivos.

## Huiro App

Práctica rítmica y patrones.

## Presentador Pedagógico

Sistema de presentaciones basadas en texto ejecutable.

## Biblioteca Musical

Repositorio central de:

* MIDIs
* ejercicios
* canciones
* clases
* actividades

---

# Integración total

Todas las apps deben poder:

* compartir metadata
* abrir recursos entre sí
* reutilizar ejercicios
* leer secciones MIDI
* proyectarse dentro del Presentador Pedagógico

---

# Formato de datos

Priorizar:

* MIDI
* JSON
* texto estructurado

Evitar:

* archivos pesados
* formatos propietarios
* dependencias complejas

---

# Requisitos técnicos

* React
* Tailwind
* Tone.js
* IndexedDB
* PWA
* responsive
* autosave
* offline-first

---

# Objetivo UX

Reducir al mínimo:

* abrir programas
* configurar cosas
* mover archivos
* depender de hardware específico

La experiencia debe sentirse:

* inmediata
* fluida
* portátil
* musical
* simple

---

# Idea central

No crear “software musical profesional”.

Crear:

# herramientas web musicales para flujo pedagógico real.
