# Prompt — Presentador Pedagógico

Quiero desarrollar una aplicación web llamada “Presentador Pedagógico”.

La app debe reemplazar PowerPoint, Gamma App y Canva para clases de música.

NO quiero crear archivos PPT.
NO quiero diseñar diapositivas manualmente.

Quiero escribir texto simple estructurado y que la app automáticamente genere presentaciones proyectables de alto contraste y texto gigante.

La filosofía es:
“texto ejecutable para clases musicales”.

---

# Tecnologías sugeridas

* React
* Tailwind
* PWA
* Tone.js
* YouTube Embed API
* Markdown parser personalizado

---

# Objetivo principal

Permitir escribir rápidamente una clase usando texto simple y proyectarla inmediatamente.

La app debe:

* interpretar sintaxis simple
* generar diapositivas automáticamente
* incrustar herramientas musicales del ecosistema
* funcionar fullscreen

---

# Diseño visual

* fondo oscuro
* texto blanco
* contraste extremo
* tipografía enorme
* máxima legibilidad
* minimalismo total

Debe verse bien:

* en proyectores malos
* desde el fondo de la sala
* en salas iluminadas

---

# Navegación

## Teclado

* espacio
* enter
* flechas

## Touch

* swipe
* tap lateral

## Control remoto celular

Permitir controlar la presentación desde otro dispositivo.

---

# Filosofía UX

La app NO debe sentirse como software de diseño.

Debe sentirse como:

* escribir apuntes
* escribir un guion
* ejecutar una clase

El objetivo es eliminar:

* PowerPoint
* Gamma
* Canva
* edición manual de diapositivas
* mover cajas de texto

Y reemplazarlo por:

* texto estructurado
* proyección instantánea
* integración musical viva.
