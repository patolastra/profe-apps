# Prompt — Cuaderno MIDI

Quiero desarrollar una aplicación web llamada “Cuaderno MIDI”.

La app debe funcionar en navegador (desktop y celular) y estar orientada a captura rápida de ideas musicales y creación de MIDIs livianos, sin depender de DAWs pesados.

La filosofía NO es replicar Ableton, FL Studio o REAPER.
La app debe sentirse como una libreta musical rápida, minimalista e inmediata.

## Objetivo principal

Permitir escribir melodías rápidamente y exportarlas como MIDI, usando una interfaz extremadamente simple y optimizada para flujo musical rápido.

---

# Tecnologías sugeridas

* React
* Tailwind
* Tone.js
* MidiWriterJS
* Web MIDI API
* IndexedDB
* PWA

---

# Funciones principales

## Teclado musical

* teclado visual de 2 octavas
* soporte cromático completo
* click = escuchar nota
* Ctrl + click = insertar nota en melodía
* octava up/down vía teclado
* navegación rápida con teclado físico

---

# Modos musicales

## Modo absoluto

Las notas representan notas reales.

## Modo relativo tonal

El usuario elige tonalidad y el teclado se transpone funcionalmente:

* Do visual = tónica real
* Re visual = segundo grado
  etc.

---

# Escritura melódica

La melodía se ingresa inicialmente SIN ritmo.

El usuario:

* escucha notas
* reconoce
* inserta
* navega entre notas
* modifica alturas rápidamente

La edición debe sentirse más cercana a editar texto que a usar un piano roll profesional.

---

# Captura rítmica posterior

Después de ingresar alturas:

* el usuario define BPM mediante tap tempo
* se activa metrónomo
* el usuario presiona una tecla siguiendo el ritmo
* cada pulsación asigna duración a la siguiente nota

Opciones:

* cuantización
* swing
* tripletes
* humanización

---

# Piano roll minimalista

* horizontal
* limpio
* bloques grandes
* táctil
* editable
* sin interfaz DAW compleja

---

# Metadata MIDI

Permitir guardar:

* título
* artista
* estilo
* comentarios
* BPM
* tonalidad

Y exportarlos dentro del archivo MIDI mediante metadata estándar.

---

# Secciones MIDI

Permitir definir:

* Intro
* A
* B
* Coro
* Puente
* Final
* Personalizadas

Usando:

* Marker Events
* Cue Points
* metadata estructurada

Esto permitirá que otras apps del ecosistema lean las secciones automáticamente.
